## ✨ ¿Qué es?

Una colección de juegos en 3D pensada como **recurso educativo** para ejercitar la memoria de trabajo visoespacial, la rotación mental y la planificación. Todo corre en el navegador, sin instalar nada.

## 🎮 Los juegos

| | Juego | Qué entrena |
|---|---|---|
| 🧊 | **Grilla de memoria 3D** | Memoria visoespacial: se iluminan cubitos, se apagan y el cubo gira. Hay que tocar los que recordás y, si acertás, sube el nivel. |
| 🎲 | **Cubo Rubik: desafío** | Razonamiento espacial y planificación: mirás cómo se mezcla el cubo (un movimiento más por nivel) y lo deshacés con la menor cantidad de giros posible. |
| 🌈 | **Cubo Rubik: estilo libre** | Empieza resuelto. Girá lo que quieras, mezclalo, deshacé jugadas, o pedí ayuda. |
| ⭕ | **Ta-Te-Ti 3D (3 fichas)** | Planificación y anticipación, contra la compu (fácil, medio o difícil) o con un amigo. |
| 🔜 | Secuencia 3D y Conteo rápido | Próximamente. |

## 🆘 Ayudas en el cubo Rubik

- 📖 **Guía:** enseña el método paso a paso y puede ejecutar cada algoritmo.
- 💡 **Pista:** marca el próximo giro.
- ✨ **Resolver:** lo resuelve solo.

## 🛠️ Cómo está hecho

Un sitio estático con [p5.js](https://p5js.org/) (WebGL). No necesita servidor.

```
index.html   Menú y pantallas
sketch.js    Grilla de memoria y control general
rubik.js     Cubo Rubik, mezcla, pistas y solución
guia.js      Guía paso a paso para resolver el cubo
tateti.js    Ta-Te-Ti 3D de 3 fichas
style.css    Estilos
```
